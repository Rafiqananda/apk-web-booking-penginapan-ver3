STAYNEST VERSI 1 - TAMPILAN LAMA + FITUR TAMBAHAN
==================================================

Versi ini mempertahankan halaman utama dan gaya visual dasar dari StayNest Versi 1,
kemudian menambahkan halaman login, profil, admin, kategori, fasilitas, dan peta Google Maps interaktif.

MENJALANKAN:
1. Extract ZIP.
2. Buka folder StayNest_Versi_1_TampilanLama_FiturLengkap di VS Code.
3. Jalankan index.html dengan Live Server.
4. Buka menu Penginapan.

GOOGLE MAPS:
- Buka penginapan.html.
- Cari YOUR_GOOGLE_MAPS_API_KEY.
- Ganti dengan API key Google Maps milik sendiri.
- Aktifkan Maps JavaScript API pada Google Cloud Console.
- Billing mungkin diperlukan sesuai ketentuan Google.
- Tanpa API key valid, peta interaktif dan marker tidak akan muncul.
